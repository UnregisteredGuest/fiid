Welcome to F.I.I.D, the Food Insecurity Information Database

We, team S.E.A.D., aim to improve the aid provided by social impact oriented organizations by creating and maintaining a web portal that provides pertinent information about food insecurity. The data behind this project is sourced from various public sources. The project serves as a system to consolidate them in order to reduce the necessity of conducting research so that projects addressing world hunger can focus more on execution.
